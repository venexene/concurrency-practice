# 009. Молекулы воды

**Сложность:** Medium

**Темы:** горутины, синхронизация, групповой барьер

## Условие

Реализуйте тип `Water`, конструктор `NewWater() *Water` и методы
`Hydrogen(emit func())` и `Oxygen(emit func())`.

Тестовый код создаёт **один объект** `Water` и запускает отдельную горутину
для каждого атома. Каждая горутина вызывает свой метод **один раз**:
`water.Hydrogen(emitH)` для H или `water.Oxygen(emitO)` для O. Всего будет
`2m` вызовов `Hydrogen` и `m` вызовов `Oxygen`; порядок их запуска неизвестен.
Дополнительные горутины внутри методов создавать не требуется.

`emitH()` и `emitO()` — переданные тестовым кодом функции без аргументов.
Первая добавляет `"H"` в общий журнал, вторая — `"O"`. Они могут временно
блокироваться, но затем завершаются. Журнал тестового кода потокобезопасен.
Каждый вызов метода должен дождаться возврата своего callback.

Согласуйте вызовы так, чтобы атомы образовывали молекулы по **два H и один O**.
Каждая последовательная тройка записей журнала должна содержать ровно два
`"H"` и одно `"O"`. Порядок внутри тройки произволен: `H,H,O`, `H,O,H` и
`O,H,H` одинаково допустимы. Callbacks атомов одной молекулы могут
выполняться одновременно, но это не обязательно.

**Следующую молекулу нельзя начинать, пока не вернулись все три callbacks
текущей.** Если один из них задержался, атомы следующей тройки должны ждать,
даже если уже пришли. После обработки всех атомов каждый вызов метода должен
завершиться.

## Ограничения

- `0 <= m <= 1000`.
- Всегда поступает ровно `2m` атомов H и `m` атомов O.
- При `m=0` вызовов методов нет.
- Используйте стандартную библиотеку Go. Не устанавливайте порядок работы
  горутин через `time.Sleep` или активное ожидание.

## Примеры

В записи `parallel{...}` каждый символ означает отдельную горутину: `H` —
вызов `Hydrogen(emitH)`, `O` — вызов `Oxygen(emitO)`. Все вызовы запускаются
конкурентно, после чего тестовый код ждёт их завершения.

```text
Вход: m=1; water=NewWater(); parallel{O, H, H}
Один допустимый выход: ["O", "H", "H"]
Пояснение: три вызова образовали одну молекулу. Также допустимы H,O,H и H,H,O.
```

```text
Вход: m=2; water=NewWater(); parallel{O, H, H, H, O, H}
Один допустимый выход: ["H", "O", "H", "H", "H", "O"]
Пояснение: первые три записи и последние три записи — две отдельные молекулы.
          Если callback первой тройки ещё выполняется, ни один callback
          второй тройки не может начаться.
```

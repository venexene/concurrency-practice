# 004. Дождаться всех квадратов

**Сложность:** Easy

**Темы:** горутины, ожидание завершения, слайсы

## Условие

Реализуйте `Squares(nums []int64) []int64`. Для каждого элемента `nums`
запустите отдельную горутину, которая вычислит его квадрат. Верните новый
слайс той же длины: на позиции `i` должен находиться квадрат `nums[i]`.
Порядок результата должен совпадать с порядком входа независимо от порядка
выполнения горутин.

Функция должна дождаться завершения всех запущенных горутин перед возвратом.
Исходный слайс изменять нельзя. Не записывайте результаты в общий слайс
через конкурентный `append`.

## Ограничения

- `0 <= len(nums) <= 10^4`.
- Пустой вход даёт пустой результат.
- Квадраты всех входных чисел помещаются в `int64`.
- Используйте стандартную библиотеку Go. Не устанавливайте порядок
  выполнения горутин с помощью `time.Sleep` или активного ожидания.

## Примеры

```text
Вход: nums=[3, -2, 0]
Выход: [9, 4, 0]
```

```text
Вход: nums=[]
Выход: []
```

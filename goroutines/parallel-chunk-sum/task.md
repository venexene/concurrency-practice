# 005. Параллельная сумма блоков

**Сложность:** Easy

**Темы:** горутины, ожидание завершения, независимые результаты

## Условие

Реализуйте `ChunkSum(nums []int64, k int) int64`. Разбейте `nums` на `k`
смежных блоков в исходном порядке. Размеры блоков должны отличаться не более
чем на один элемент. Если элементы не делятся поровну, первые блоки получают
по одному дополнительному элементу. При `k > len(nums)` оставшиеся блоки пусты.

Для каждого блока запустите отдельную горутину, которая вычислит его сумму.
После завершения вычислений сложите частичные суммы и верните результат.
Входной слайс не изменяйте. Конкурентные вызовы функции должны быть безопасны.

## Ограничения

- `0 <= len(nums) <= 10^5`.
- `1 <= k <= 1000`.
- Суммы не выходят за пределы `int64`; переполнение проверять не нужно.
- Используйте стандартную библиотеку Go. Не устанавливайте порядок выполнения
  горутин через `time.Sleep` или активное ожидание.

## Примеры

```text
Вход: nums=[1, 2, 3, 4, 5], k=3
Выход: 15
Пояснение: блоки [1, 2], [3, 4], [5], частичные суммы 3, 7 и 5.
```

```text
Вход: nums=[1, 2, 3, 4, 5, 6, 7, 8], k=3
Выход: 36
Пояснение: блоки [1, 2, 3], [4, 5, 6], [7, 8].
```

```text
Вход: nums=[4, -1], k=4
Выход: 3
Пояснение: блоки [4], [-1], [], []. Пустые блоки дают сумму 0.
```

# 008. Конкурентный FizzBuzz

**Сложность:** Medium

**Темы:** горутины, порядок вывода, распределение ролей

## Условие

Реализуйте тип `FizzBuzz`, конструктор `NewFizzBuzz(n int) *FizzBuzz` и четыре
метода:

- `Fizz(emit func())` отвечает за числа, кратные 3, но не 5. Его callback
  добавляет в журнал строку `"fizz"`.
- `Buzz(emit func())` отвечает за числа, кратные 5, но не 3. Его callback
  добавляет строку `"buzz"`.
- `FizzBuzz(emit func())` отвечает за числа, кратные и 3, и 5. Его callback
  добавляет строку `"fizzbuzz"`.
- `Number(emit func(int))` отвечает за остальные числа. Он передаёт число
  в `emit(x)`, а callback добавляет его в журнал.

Первые три callbacks не принимают аргументов: метод вызывает `emit()`, а
переданная тестовым драйвером функция уже знает, какую строку записать.
Самим методам печатать строки через `fmt.Println` не нужно.

Тестовый драйвер создаёт один объект и запускает каждый метод ровно один раз
в отдельной горутине. Совместно они должны пройти числа от `1` до `n` по
порядку. Для каждого числа вызывается ровно один callback из нужного метода.
Порядок запуска горутин не должен менять журнал. Вызовы callbacks не должны
пересекаться. Когда все числа обработаны, все четыре метода возвращаются,
в том числе методы, которым ни разу не достался ход. Каждый callback вызывает
именно метод своей категории, а не общая вспомогательная горутина.

## Ограничения

- `0 <= n <= 10^4`.
- При `n=0` все методы завершаются без вызовов callbacks.
- Используйте стандартную библиотеку Go. Не устанавливайте порядок через
  `time.Sleep` или активное ожидание.

## Примеры

`parallel{Fizz, Buzz, FizzBuzz, Number}` означает одновременный запуск всех
четырёх методов с ожиданием их завершения.

```text
Вход: n=5; parallel{Fizz, Buzz, FizzBuzz, Number}
Выход: [1, 2, "fizz", 4, "buzz"]
Пояснение: Number выводит 1, 2 и 4; Fizz выводит "fizz" для 3;
          Buzz выводит "buzz" для 5. FizzBuzz ничего не выводит, но завершится.
```

```text
Вход: n=15; parallel{Fizz, Buzz, FizzBuzz, Number}
Выход: [1, 2, "fizz", 4, "buzz", "fizz", 7, 8, "fizz", "buzz", 11, "fizz", 13, 14, "fizzbuzz"]
```

```text
Вход: n=0; parallel{Fizz, Buzz, FizzBuzz, Number}
Выход: []
```

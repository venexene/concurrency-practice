# 006. Сигнал для всех

## Инсайт

Закрытый канал подходит для общего сигнала: все, кто уже ждёт чтения,
разблокируются, а новые чтения сразу завершаются.

## Решение

В `NewLatch` создаю канал. `Wait` читает из него и до открытия блокируется.
`Release` закрывает канал через `sync.Once`, поэтому несколько одновременных
или повторных вызовов не пытаются закрыть его дважды.

## Что важно запомнить

- Чтение из закрытого канала не потребляет сигнал. После первого `Release`
  защёлка остаётся открытой навсегда.
- `sync.Once` нужен именно для безопасного однократного закрытия: повторный
  `close` вызвал бы панику.
- Создавать объект нужно через `NewLatch`: у нулевого значения `Latch` канал
  равен `nil`, и `Wait` на нём заблокируется навсегда. Условие не требует
  работоспособности нулевого значения.

## Проверка

Тесты проверяют, что ожидающие блокируются до `Release`, все пробуждаются
после него, будущий `Wait` проходит сразу, повторные конкурентные `Release`
безопасны, а два экземпляра не влияют друг на друга.

```sh
go test -race -timeout 30s ./goroutines/broadcast-latch
```

Тесты прошли, race detector гонок не нашёл.

## Оценка

Ошибок в реализации для заданного контракта не обнаружено.

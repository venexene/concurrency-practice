# 006. Сигнал для всех

**Сложность:** Easy

**Темы:** синхронизация горутин, широковещательный сигнал

## Условие

Реализуйте тип `Latch`, конструктор `NewLatch() *Latch` и методы `Wait()` и
`Release()`.

Новый `Latch` закрыт: каждый вызов `Wait()` блокируется. Первый вызов
`Release()` открывает его и позволяет завершиться **всем** ожидающим вызовам
`Wait()`. После этого любой новый `Wait()` возвращается без ожидания. Сигнал
общий: один ожидающий не может «забрать» его у остальных.

Повторные вызовы `Release()`, в том числе одновременные из разных горутин,
должны быть безопасны. Открытый `Latch` больше не закрывается.

## Ограничения

- До `10^3` горутин могут одновременно вызывать методы одного объекта.
- Объект создаётся через `NewLatch`; поддерживать нулевое значение `Latch`
  не требуется.
- Используйте стандартную библиотеку Go. Не устанавливайте порядок выполнения
  горутин через `time.Sleep` или активное ожидание.

## Примеры

`start A=Wait()` запускает вызов в отдельной горутине без ожидания его конца;
`join A` дожидается завершения этого вызова. Запись `parallel{...}` означает
одновременный запуск перечисленных вызовов с ожиданием их завершения.

```text
Вход: latch=NewLatch(); start A=Wait(); start B=Wait(); Release(); join A; join B; Wait()
Выход: A=done, B=done, последний Wait=done
Пояснение: оба вызова завершаются после Release(), даже если успели
          заблокироваться до него. Новый Wait() уже не блокируется.
```

```text
Вход: latch=NewLatch(); Release(); parallel{Release(); Release()}; Wait()
Выход: Wait=done, panic=false
Пояснение: повторные одновременные Release() не меняют открытое состояние.
```

# 007. Кольцо участников

**Сложность:** Easy

**Темы:** горутины, синхронизация, передача хода

## Условие

Реализуйте `Ring(k, rounds int, emit func(int))`. В кольце участвуют `k`
горутин с номерами от `0` до `k-1`. Они должны вызывать `emit` по очереди:
сначала горутина `0`, затем `1` и так далее до `k-1`, после чего снова `0`.
Повторите полный круг ровно `rounds` раз. Номер участника может передать в
`emit` только соответствующая горутина.

`emit(x)` — предоставленная функция, которая добавляет `x` в журнал вывода.
Вызовы `emit` не должны выполняться одновременно. Всего должно быть ровно
`k * rounds` вызовов. Перед возвратом из `Ring` завершите всех запущенных
участников. Разные вызовы `Ring` должны быть безопасны при одновременном
запуске.

Если `rounds=0`, не вызывайте `emit` и завершите функцию. При `k=1`
единственная горутина выводит `0` по одному разу за круг.

## Ограничения

- `1 <= k <= 100`.
- `0 <= rounds <= 1000`.
- Используйте стандартную библиотеку Go. Не устанавливайте порядок через
  `time.Sleep` или активное ожидание.

## Примеры

```text
Вход: k=3, rounds=2
Выход: [0, 1, 2, 0, 1, 2]
```

```text
Вход: k=1, rounds=3
Выход: [0, 0, 0]
```

```text
Вход: k=4, rounds=0
Выход: []
```

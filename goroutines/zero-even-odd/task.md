# 003. Ноль, чётное, нечётное

**Сложность:** Easy

**Темы:** горутины, координация трёх участников

## Условие

Реализуйте `ZeroEvenOdd(n)` с методами `Zero(emit func(int))`,
`Even(emit func(int))` и `Odd(emit func(int))`. Каждый метод вызывается
ровно один раз из своей горутины в произвольном порядке.

Три метода должны вместе вывести числа от 1 до n, вставляя 0 перед каждым:
`0, 1, 0, 2, ..., 0, n`.

- `Zero` выводит только нули, ровно n раз.
- `Even` выводит только чётные числа от 1 до n, каждое один раз.
- `Odd` выводит только нечётные числа от 1 до n, каждое один раз.

`emit` — функция, которую передаёт вызывающий код, например тест. Она записывает
число в журнал результата и завершается без паники. Обеспечить порядок
вызовов должны методы `ZeroEvenOdd`; полагаться на синхронизацию внутри `emit`
нельзя. Следующий `emit` начинается только после завершения предыдущего.

Каждый метод возвращается после всех своих вызовов `emit`. Все три метода
должны завершиться, даже если для участника нет чисел: при n=0 вывод пуст,
а при n=1 метод `Even` ничего не выводит.

## Ограничения

- `0 <= n <= 10^4`.
- Объект создаётся через `NewZeroEvenOdd(n)` и используется один раз.
- Каждый метод вызывается ровно один раз из отдельной горутины.
- Порядок запуска и скорость горутин произвольны.
- Используйте стандартную библиотеку Go; число каналов не ограничено.
- `time.Sleep` для установления порядка и активное ожидание запрещены.
- Гонки данных и оставшиеся после выполнения горутины недопустимы.

## Примеры

```text
Вход: n=4; parallel{Even, Zero, Odd}
Выход: [0, 1, 0, 2, 0, 3, 0, 4]
```

```text
Вход: n=1; parallel{Odd, Even, Zero}
Выход: [0, 1]
```

```text
Вход: n=0; parallel{Zero, Even, Odd}
Выход: []
```

`parallel{...}` означает запуск методов в отдельных горутинах и ожидание
завершения всех трёх.

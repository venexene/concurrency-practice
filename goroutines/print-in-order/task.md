# 001. Сначала первое

**Сложность:** Easy

**Темы:** горутины, синхронизация

## Условие

Реализуйте `Ordered` с методами `First`, `Second`, `Third`. Каждый метод
вызывается ровно один раз из своей горутины в произвольном порядке.
Они должны записать `first`, `second`, `third` именно в таком порядке.

Каждый метод принимает `emit func(string)`:

- `First(emit func(string))` вызывает `emit("first")`.
- `Second(emit func(string))` вызывает `emit("second")`.
- `Third(emit func(string))` вызывает `emit("third")`.

`emit` — функция, которую передаёт вызывающий код, например тест. Она добавляет
строку в журнал результата. Реализовывать её внутри `Ordered` не нужно.
Порядок вызовов обеспечивает `Ordered`.

Следующий вызов `emit` может начаться только после завершения предыдущего.
Каждый метод возвращается после завершения своего `emit`. После выполнения
всех трёх методов все вызвавшие их горутины должны завершиться.

## Ограничения

- Объект создаётся через `NewOrdered()` и используется один раз.
- Три горутины; каждый метод вызывается ровно один раз.
- Нельзя предполагать порядок запуска или скорость выполнения горутин.
- Каждый `emit` должен быть вызван ровно один раз со строкой своего метода.
- `emit` завершается без паники; полагаться на его внутреннюю синхронизацию нельзя.
- Используйте стандартную библиотеку Go. `time.Sleep` для установления порядка
  и активное ожидание запрещены.

## Пример

```text
Вход: parallel{Third, First, Second}
Выход: ["first", "second", "third"]
```

`parallel{...}` означает запуск каждого метода в отдельной горутине и ожидание
завершения всех трёх. При любом порядке запуска журнал должен содержать
`first`, `second`, `third`.

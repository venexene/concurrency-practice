# 002. Ping и pong

**Сложность:** Easy

**Темы:** горутины, передача хода

## Условие

Реализуйте `PingPong(n)` с методами `Ping(emit func(string))` и
`Pong(emit func(string))`. Каждый метод вызывается ровно один раз из своей
горутины; порядок запуска произвольный.

`Ping` должен вызвать `emit("ping")` ровно n раз, `Pong` — `emit("pong")`
ровно n раз. Общий журнал начинается с `ping` и строго чередуется.
Вызовы `emit` не должны перекрываться; каждый метод возвращается после
завершения всех своих вызовов `emit`.

`emit` — переданная вызывающим кодом функция, записывающая строку в результат.
Она завершается без паники. Синхронизацию обеспечивает `PingPong`.

Оба метода должны завершиться, включая случай n=0. При n=0 журнал пуст.

## Ограничения

- `0 <= n <= 10^4`.
- Объект создаётся через `NewPingPong(n)` и используется один раз.
- Два участника; нельзя предполагать порядок запуска или скорость горутин.
- Используйте стандартную библиотеку Go.
- `time.Sleep` для установления порядка и активное ожидание запрещены.
- Гонки данных и оставшиеся после выполнения горутины недопустимы.

## Примеры

```text
Вход: n=3; parallel{Pong, Ping}
Выход: ["ping", "pong", "ping", "pong", "ping", "pong"]
```

```text
Вход: n=0; parallel{Ping, Pong}
Выход: []
```

`parallel{...}` означает запуск методов в отдельных горутинах и ожидание
завершения обоих.

# 010. Многоразовый барьер

**Сложность:** Medium

**Темы:** синхронизация горутин, повторное использование барьера

## Условие

Реализуйте тип `Barrier`, конструктор `NewBarrier(n int) *Barrier` и метод
`(b *Barrier) ArriveAndWait() int`.

Один объект `Barrier` используют ровно `n` постоянных участников — отдельных
горутин. Каждый участник выполняет работу одного раунда, вызывает
`ArriveAndWait()` и останавливается, пока до того же барьера не дойдут все
остальные. Только после прибытия **всех `n` участников** их вызовы могут
вернуться. Порядок возврата не задан.

Первый раунд называется **поколением 0**: все его вызовы возвращают `0`.
Затем те же участники снова могут вызвать метод. Во втором раунде каждый
ждёт остальных и получает `1`, в третьем — `2` и так далее. Барьер нельзя
считать одноразовым: он должен снова закрываться для каждого нового раунда.

Участник входит в следующий раунд только после возврата из своего предыдущего
вызова. При этом он может успеть вызвать метод снова, пока другой участник
ещё выходит из прошлого раунда. Вызовы разных поколений не должны смешаться:
ранний участник следующего раунда ждёт остальные вызовы **этого же** раунда.

## Ограничения

- `1 <= n <= 1000`; число участников не меняется после создания объекта.
- Каждый из `n` участников вызывает метод один раз за раунд; никто не уходит
  и не отменяет ожидание.
- При `n=1` каждый вызов возвращается без ожидания: последовательно `0`,
  затем `1`, `2` и так далее.
- Используйте стандартную библиотеку Go. Не устанавливайте порядок через
  `time.Sleep` или активное ожидание.

## Примеры

В записи `parallel{...}` вызовы запускаются в разных горутинах, после чего
тестовый код дожидается их завершения.

```text
Вход: b=NewBarrier(2); parallel{A=b.ArriveAndWait(), B=b.ArriveAndWait()}
Выход: A=0, B=0
Пояснение: первый пришедший ждёт второго. После его прихода оба могут выйти.
```

```text
Вход: b=NewBarrier(2); parallel{A=b.ArriveAndWait(), B=b.ArriveAndWait()};
      parallel{A=b.ArriveAndWait(), B=b.ArriveAndWait()}
Выход: первый раунд [0, 0], второй раунд [1, 1]
```

```text
Вход: b=NewBarrier(1); три последовательных вызова ArriveAndWait()
Выход: [0, 1, 2]
```

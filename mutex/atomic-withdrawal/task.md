# 023. Атомарное снятие средств

**Сложность:** Medium

**Темы:** общая память, мьютекс, неделимая проверка и изменение

## Условие

Реализуйте счёт `Account` с начальным балансом и методами:

```go
func NewAccount(balance int64) *Account
func (a *Account) Deposit(n int64)
func (a *Account) Withdraw(n int64) bool
func (a *Account) Balance() int64
```

`Deposit(n)` пополняет счёт на `n`. `Withdraw(n)` возвращает `true` и
уменьшает баланс на `n`, если денег достаточно. Иначе метод возвращает
`false` и оставляет баланс прежним. Проверка достаточности средств и
списание должны быть одной неделимой операцией. `Balance()` возвращает
согласованное текущее значение.

Все три метода одного счёта могут вызываться одновременно. Баланс не должен
становиться отрицательным; два конкурентных снятия не могут оба использовать
одни и те же деньги. Для защиты общего состояния используйте мьютекс.

## Ограничения

- Начальный баланс неотрицателен.
- Для `Deposit` и `Withdraw` передаётся `n > 0`.
- До `10^5` вызовов методов и до `10^3` вызывающих горутин.
- Переполнение `int64` не проверяется.
- Используйте стандартную библиотеку Go. Не устанавливайте порядок вызовов
  через `time.Sleep` или активное ожидание.
- Не копируйте счёт после начала использования вместе с его блокировкой.

## Пример

`parallel{...}` запускает перечисленные вызовы конкурентно и ждёт завершения
каждого из них. Порядок результатов двух снятий может различаться.

```text
Вход: balance=10; parallel{Withdraw(7), Withdraw(7)}; Balance()
Один допустимый выход: [true, false]; 3
```

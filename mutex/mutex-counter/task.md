# 021. Счётчик без потерянных обновлений

**Сложность:** Easy

**Темы:** общая память, блокировка, конкурентные обновления

## Условие

Реализуйте тип `Counter` с методами:

```go
func (c *Counter) Add(delta int64)
func (c *Counter) Value() int64
```

Начальное значение счётчика — `0`. `Add` прибавляет переданное `delta` ровно
один раз; `Value` возвращает согласованное текущее значение. Методы одного
счётчика могут вызываться одновременно из разных горутин. Обновления не должны
теряться, а чтение не должно видеть промежуточное состояние операции.

Для защиты общего состояния используйте мьютекс. Атомарные операции и
отдельная горутина, обслуживающая счётчик, не допускаются.

## Ограничения

- Отрицательные и нулевые значения `delta` допустимы.
- Счётчик нельзя копировать после начала использования: копия блокировки не
  защищала бы общее состояние исходного объекта.
- До `10^5` вызовов методов и до `10^3` вызывающих горутин.
- Переполнение `int64` не проверяется.
- Используйте стандартную библиотеку Go. Не устанавливайте порядок вызовов
  через `time.Sleep` или активное ожидание.

## Пример

`parallel{...}` означает, что перечисленные вызовы запускаются конкурентно и
драйвер дожидается завершения каждого из них. После этого вызывается `Value`.

```text
Вход: parallel{Add(3), Add(-1), Add(5)}; Value()
Выход: 7
```

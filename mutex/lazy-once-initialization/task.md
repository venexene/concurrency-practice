# 026. Инициализация ровно один раз

**Сложность:** Medium

**Темы:** `sync.Once`, отложенная инициализация, публикация результата

## Условие

Реализуйте объект `Lazy` с таким API:

```go
type Config struct {
    Port int
}

func NewLazy(load func() (Config, error)) *Lazy
func (l *Lazy) Get() (Config, error)
```

`load` — функция, которую передаёт вызывающий код при создании `Lazy`.
Она получает конфигурацию, например читает её из файла. Саму `load`
реализовывать не нужно. Конструктор только сохраняет эту функцию: до
первого вызова `Get` она не должна выполняться.

Первый начавший инициализацию вызов `Get` выполняет `load` **ровно один
раз**. Если в это время другие горутины вызывают `Get`, они ждут окончания
`load`. После этого все текущие и будущие вызовы `Get` возвращают одну
и ту же пару результатов `(Config, error)`. Повторно вызывать `load`
нельзя, даже если она вернула ошибку.

Здесь `Config` содержит только поля-значения и считается неизменяемым
после загрузки. Возвращённую структуру можно передавать по значению:
изменение своей копии вызывающим кодом не меняет результат будущих `Get`.

## Ограничения

- Используйте `sync.Once` или `sync.OnceValues`.
- `load` не равна `nil`, завершается и не вызывает `panic`.
- `Get` может вызываться одновременно из разных горутин; до `10^3`
  вызовов могут ожидать результат.
- Используйте стандартную библиотеку Go. Не устанавливайте порядок
  выполнения горутин через `time.Sleep` или активное ожидание.

## Примеры

`parallel{...}` запускает перечисленные вызовы конкурентно и ждёт
завершения каждого. `loadCalls` — счётчик вызовов переданной функции,
который ведёт тестовый код.

```text
Вход: load возвращает (Config{Port: 8080}, nil);
      l := NewLazy(load); parallel{l.Get(), l.Get(), l.Get()}
Выход: каждый Get возвращает (Config{Port: 8080}, nil); loadCalls=1
```

```text
Вход: load возвращает (Config{}, ErrLoad);
      l := NewLazy(load); l.Get(); l.Get()
Выход: оба Get возвращают (Config{}, ErrLoad); loadCalls=1
```

Если после `NewLazy(load)` ни разу не вызвать `Get`, то `loadCalls=0`.

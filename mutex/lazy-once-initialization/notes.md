# 026. Инициализация ровно один раз

## Инсайт

`load` нужно запускать только при первом `Get`, а её результат сохранить
для всех последующих вызовов. Если несколько горутин одновременно вызывают
`Get`, они должны дождаться завершения одной и той же загрузки.

## Решение

Храню переданную функцию `load`, результат `cfg`, ошибку `err` и
`sync.Once` внутри `Lazy`. Конструктор только запоминает функцию.
`Get` выполняет `load` через `once.Do`, поэтому загрузка запускается
не более одного раза. После завершения `Do` возвращаю сохранённые поля.

Стоимость первого `Get` включает работу `load`; последующие вызовы
выполняют `O(1)` работы без учёта возможного ожидания `Do`. Дополнительная
память объекта — `O(1)`, новых горутин решение не создаёт.

## Что пошло не так

- Раньше перед `once.Do` стояла проверка `if l.err != nil`, которая
  возвращала `(Config{}, l.err)`. Если `load` вернула
  `(Config{Port: 1234}, ErrLoad)`, первый `Get` возвращал эту пару,
  а второй и следующие — `(Config{}, ErrLoad)`. Это нарушало условие
  об одинаковом результате. Проверка удалена; теперь все вызовы
  возвращают сохранённые `cfg` и `err`. Тест с таким результатом
  загрузки проходит.

## Что важно запомнить

- Ошибка тоже является частью сохранённого результата. Она не должна
  приводить ни к повторному вызову `load`, ни к изменению второго
  результата по сравнению с первым вызовом.
- `sync.Once` обеспечивает однократное выполнение, ожидание его
  завершения другими вызовами и видимость записанных `cfg` и `err`
  после возврата из `Do`. Отдельный мьютекс здесь не нужен: поля
  больше не изменяются. Раньше дополнительный `mu` сериализовал даже
  готовые вызовы `Get`; теперь он убран.
- `Config` содержит только `int`, поэтому возвращение структуры по
  значению даёт вызывающему коду собственную копию.

## Проверка

Тесты проверяют, что конструктор не вызывает `load`, повторные и
конкурентные `Get` вызывают её один раз, конкурирующие вызовы ждут
завершения загрузки, ошибка сохраняется, а изменение возвращённой
копии конфигурации не влияет на будущие результаты.

```sh
go test -race -timeout 10s ./mutex/lazy-once-initialization
```

Тесты прошли, включая `TestLazyCachesCompleteErrorResult`;
race detector не сообщил о гонках. Проверка этих сценариев не доказывает
корректность для всех расписаний горутин.

## Оценка

Ошибок в текущем решении в пределах проверенного контракта не
обнаружено.

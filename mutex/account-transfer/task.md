# 025. Обмен между счетами

**Сложность:** Medium

**Темы:** несколько мьютексов, порядок захвата, неделимый перевод

## Условие

Реализуйте банковские счета и перевод между ними:

```go
func NewAccount(balance int64) *Account
func (a *Account) Balance() int64
func Transfer(from, to *Account, amount int64) bool
```

Конструктор создаёт счёт с заданным балансом. У каждого счёта есть
собственный мьютекс и уникальный неизменяемый ID.
`Transfer` проверяет достаточность средств на счёте `from`, списывает
`amount` и зачисляет его на `to` как одну неделимую операцию. Если денег
недостаточно, метод возвращает `false` без изменения обоих балансов; при
успехе возвращает `true`. Общая сумма денег сохраняется. `Balance`
безопасен при конкурентных вызовах и возвращает согласованное значение
одного счёта.

Одновременные переводы, включая переводы в противоположных направлениях,
должны завершаться без взаимной блокировки. Перевод счёта самому себе
возвращает `true` без изменений, если средств достаточно; при нехватке
средств возвращает `false`.

## Ограничения

- Начальные балансы неотрицательны; `amount > 0`.
- Единый глобальный мьютекс для всех счетов запрещён.
- Используйте только стандартную библиотеку Go.
- До `10^5` вызовов и до `10^3` вызывающих горутин, если не указано иное.
- Переполнение `int64` не проверяется.
- Не устанавливайте порядок выполнения через `time.Sleep` или активное
  ожидание. Счета нельзя копировать после начала использования вместе с
  их мьютексами.

## Пример

`parallel{...}` запускает перечисленные вызовы конкурентно и ждёт их
завершения. Затем читаются оба баланса.

```text
Вход: A=10, B=10; parallel{Transfer(A,B,3), Transfer(B,A,4)}; balances
Выход: оба true; A=11, B=9
```

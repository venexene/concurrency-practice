# 022. Безопасное множество

**Сложность:** Easy

**Темы:** `map`, мьютекс, конкурентный доступ

## Условие

Реализуйте множество целых чисел `IntSet` со следующими методами:

```go
func (s *IntSet) Add(x int) bool
func (s *IntSet) Remove(x int) bool
func (s *IntSet) Contains(x int) bool
```

Новое множество пусто. `Add(x)` возвращает `true`, только если добавило
отсутствовавший элемент. `Remove(x)` возвращает `true`, только если удалило
присутствовавший элемент. `Contains(x)` сообщает, есть ли элемент в множестве
на момент проверки.

Методы одного экземпляра могут вызываться одновременно. В частности, из
нескольких одновременных `Add(x)` для отсутствующего `x` ровно один должен
вернуть `true`; остальные возвращают `false`. Аналогично, если элемент
присутствует и его одновременно удаляют, ровно один `Remove(x)` возвращает
`true`. Для хранения элементов используйте обычный `map` под блокировкой.

## Ограничения

- До `10^5` различных ключей и до `10^3` вызывающих горутин.
- Используйте стандартную библиотеку Go. Не устанавливайте порядок вызовов
  через `time.Sleep` или активное ожидание.
- После начала использования не копируйте экземпляр вместе с его блокировкой.
- Нулевое значение `IntSet` не обязано быть готовым к добавлению: допустимо
  создавать пустой экземпляр через конструктор.

## Пример

`parallel{...}` запускает перечисленные вызовы одновременно и ждёт их
завершения. Порядок двух результатов `Add` зависит от расписания горутин;
ниже показан один допустимый порядок.

```text
Вход: parallel{Add(4), Add(4)}; Contains(4); Remove(4); Contains(4)
Один допустимый выход: [true, false]; true; true; false
```

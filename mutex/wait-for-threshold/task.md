# 027. Ожидание порога

**Сложность:** Medium

**Темы:** `sync.Cond`, условие ожидания, пробуждение нескольких горутин

## Условие

Реализуйте счётчик прогресса `Progress` с методами:

```go
func NewProgress() *Progress
func (p *Progress) Add(n int)
func (p *Progress) WaitAtLeast(target int)
```

Начальное значение прогресса равно `0`. `Add(n)` увеличивает его на `n`.
`WaitAtLeast(target)` блокирует вызывающую горутину, пока текущее значение
меньше `target`, и возвращается, когда значение стало не меньше порога.
Если порог уже достигнут к моменту вызова, метод возвращается сразу.

Методы могут вызываться одновременно из разных горутин. Ожидающие могут
иметь разные пороги: достижение меньшего порога не должно преждевременно
завершать ожидание большего. Когда значение достигло порога нескольких
горутин, все они должны получить возможность завершиться. Используйте
`sync.Cond` и проверяйте условие ожидания после каждого пробуждения:
само пробуждение ещё не означает, что нужный порог достигнут.

## Ограничения

- `n >= 0`, `target >= 0`.
- Тестовый драйвер в итоге увеличивает значение до каждого запрошенного
  порога; отмена и закрытие объекта не требуются.
- До `10^5` вызовов методов и до `10^3` вызывающих горутин.
- Переполнение `int` не проверяется.
- Используйте стандартную библиотеку Go. Не устанавливайте порядок
  выполнения через `time.Sleep` или активное ожидание.
- Экземпляр с мьютексом и условной переменной нельзя копировать после
  начала использования.

## Пример

`start A=...` запускает вызов в отдельной горутине без ожидания;
`join A` дожидается его завершения. Остальные команды выполняются
последовательно.

```text
Вход: start A=WaitAtLeast(2); start B=WaitAtLeast(5);
      Add(2); join A; Add(3); join B
Выход: A=done после достижения 2; B=done после достижения 5
```

При `target=0` ожидание завершается сразу, даже если `Add` ещё не вызывали.

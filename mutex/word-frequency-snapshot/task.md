# 024. Частоты слов со снимком

**Сложность:** Medium

**Темы:** `sync.RWMutex`, копирование `map`, согласованный снимок

## Условие

Реализуйте счётчик слов `WordCounter` с методами:

```go
func (w *WordCounter) Add(word string)
func (w *WordCounter) Snapshot() map[string]int
```

Изначально частота каждого слова равна нулю. `Add(word)` увеличивает частоту
этого слова на один. `Snapshot()` возвращает карту частот, соответствующую
одному целостному состоянию счётчика во время вызова. Это независимая копия:
последующие `Add` не меняют уже полученный снимок, а изменение снимка
вызывающим кодом не меняет счётчик.

Методы одного экземпляра могут вызываться конкурентно. Для защиты состояния
используйте `sync.RWMutex`: `Add` берёт блокировку на запись, а
`Snapshot` не должен брать эксклюзивную блокировку на чтение. Копирование
карты должно завершаться до освобождения блокировки на чтение.

## Ограничения

- До `10^4` различных слов.
- Вызывающий код изменяет только полученную копию карты, а не внутреннюю карту
  счётчика.
- Используйте стандартную библиотеку Go. Не устанавливайте порядок вызовов
  через `time.Sleep` или активное ожидание.
- Не копируйте экземпляр счётчика после начала использования вместе с его
  блокировкой.
- Нулевое значение `WordCounter` не обязано поддерживать `Add`: допустимо
  создавать экземпляр через конструктор.

## Пример

`parallel{...}` запускает перечисленные вызовы одновременно и ждёт их
завершения. Поэтому снимок в примере делается после всех трёх добавлений.

```text
Вход: parallel{Add("go"), Add("go"), Add("rust")}; Snapshot()
Выход: {"go": 2, "rust": 1}
```

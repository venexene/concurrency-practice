# 020. Канальная ограниченная очередь

**Сложность:** Hard

**Темы:** буферизованные каналы, отмена, закрытие, конкурентный доступ

## Условие

Реализуйте ограниченную FIFO-очередь с API:

```go
type Queue struct { /* внутреннее состояние */ }

func NewQueue(capacity int) *Queue
func (q *Queue) Put(ctx context.Context, x int) error
func (q *Queue) Get(ctx context.Context) (int, error)
func (q *Queue) Close()
```

`NewQueue` создаёт очередь ёмкостью `capacity`. `Put` добавляет значение,
дожидаясь свободного места, если очередь полна. `Get` извлекает старейшее
значение, дожидаясь его, если очередь пуста. Нулевое значение `int` — обычный
элемент.

`Close` запрещает новые добавления, будит ожидающие `Put` и `Get` и может
вызываться повторно. Все значения, принятые до закрытия, остаются доступными
через `Get` в порядке FIFO. После их извлечения `Get` возвращает `(0,
ErrClosed)`. `Put` после закрытия и `Put`, ожидавший место в момент закрытия,
возвращают `ErrClosed`. `ErrClosed` должен быть ненулевой sentinel-ошибкой,
которую можно проверить через `errors.Is`.

При отмене ожидания до выполнения операции возвращайте `ctx.Err()` (или
ошибку, для которой `errors.Is(err, ctx.Err())` истинно) и не меняйте очередь.
Если отмена совпала с выполнением операции, допустимы успешный результат или
ошибка отмены, но не частичное изменение очереди. Конкурентные `Put` и
`Close` должны безопасно определить исход: элемент либо принят до закрытия,
либо отклонён с `ErrClosed`; паники и потери принятого элемента быть не должно.

## Ограничения

- `1 <= capacity <= 10^4`.
- Методы одного экземпляра могут вызываться конкурентно из разных горутин.
- Используйте стандартную библиотеку Go. Не применяйте `time.Sleep` или
  активное ожидание для синхронизации.
- Название конструктора `NewQueue` соответствует текущему коду: в Go тип и
  функция не могут иметь одинаковое имя `Queue` в одном пакете.

## Пример

```text
Вход: q := NewQueue(2); Put(7); Put(8); Close(); Put(9);
      Get(); Get(); Get()
Выход: nil, nil, done, ErrClosed, (7, nil), (8, nil), (0, ErrClosed)
```

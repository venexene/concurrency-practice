# 017. Слить два канала

**Сложность:** Medium

**Темы:** каналы, `select`, закрытие и отключение входов

## Условие

Реализуйте функцию:

```go
func Merge2(a, b <-chan int) <-chan int
```

Она должна сразу вернуть новый канал только для чтения. В отдельной горутине
получайте значения из `a` и `b` и передавайте каждое из них в выходной канал
ровно один раз. Сохраняйте порядок **внутри каждого входа**: если из `a` сначала
пришло `1`, а потом `3`, то `1` должно появиться в выходе раньше `3`. То же
правило действует для `b`. Общий порядок значений из разных входов не задан:
он зависит от того, какие операции готовы и какую ветку выберет `select`.

Когда один вход закрылся и все его значения прочитаны, больше не выбирайте
его ветку и продолжайте читать другой вход. Закройте выход только после
исчерпания обоих входов. Вход, равный `nil`, считается отсутствующим. Если оба
входа равны `nil`, выход закрывается без значений.

## Ограничения

- Выходной канал небуферизованный; дополнительная память — `O(1)` без учёта
  каналов и одной вспомогательной горутины.
- Не закрывайте входные каналы: ими владеют их отправители.
- Потребитель читает выход до закрытия. Источники, если они не равны `nil`,
  в итоге закрываются; отмена потребителя в этот API не входит.
- Используйте стандартную библиотеку Go. Не накапливайте весь поток в слайсе,
  не используйте `time.Sleep` или активное ожидание.

## Примеры

```text
Вход: a=[1, 3], b=[2, 4]; затем оба канала закрываются
Один допустимый выход: [1, 2, 4, 3]
```

```text
Вход: a=nil, b=[5, 6]; затем b закрывается
Выход: [5, 6], затем закрытие выхода
```

# 013. Преобразование потока

**Сложность:** Easy

**Темы:** каналы, горутины, потоковая обработка

## Условие

Реализуйте функцию:

```go
func Map(in <-chan int, f func(int) int) <-chan int
```

Она создаёт и возвращает новый канал только для чтения. В отдельной горутине
функция должна получать каждое значение из `in`, применять к нему `f` и
отправлять результат в выходной канал.

Порядок результатов должен совпадать с порядком соответствующих входных
значений. Когда `in` закрывается и все его значения обработаны, выходной канал
также должен быть закрыт. Для пустого входного потока выходной канал закрывается
без значений.

## Ограничения

- Каждый элемент входного потока обрабатывается ровно один раз.
- `f` не равна `nil` и завершается без паники.
- `f` вызывается последовательно в одной горутине; она не должна вызываться
  параллельно этой реализацией.
- `Map` должна вернуть выходной канал, не дожидаясь первого значения из `in`.
- `Map` не закрывает входной канал: это обязанность его отправителя.
- Используйте стандартную библиотеку Go; не собирайте весь поток в слайс.
- Входной канал должен быть в итоге закрыт. Отмена потребителя не входит в
  контракт этой версии API.

## Примеры

```text
Вход: 1, 2, 3; f(x) = x * 10; затем close
Выход: 10, 20, 30; затем close
```

```text
Вход: close; f(x) = x + 1
Выход: канал закрыт без значений
```

# 014. Неблокирующая отправка

**Сложность:** Easy

**Темы:** каналы, `select`, `default`

## Условие

Реализуйте функцию:

```go
func TrySend(ch chan<- int, x int) bool
```

Она должна попытаться отправить `x` в `ch` и сразу вернуть результат: `true`,
если отправка состоялась, и `false`, если отправка сейчас заблокировалась бы.
При результате `false` значение не должно попасть в канал позднее.

Для буферизованного канала отправка возможна, когда в буфере есть место. Для
небуферизованного канала она возможна, когда получатель уже готов принять
значение. Если `ch == nil`, функция возвращает `false` без ожидания.

## Ограничения

- Канал не закрывается во время вызова. Отправка в закрытый канал не входит в
  контракт: в Go она вызывает панику.
- Проверять готовность через `len(ch)` и `cap(ch)` нельзя: между проверкой и
  отправкой состояние канала может измениться.
- Нельзя запускать новые горутины, использовать таймеры, `time.Sleep` или
  активное ожидание.
- Функция не закрывает переданный канал и использует только стандартную
  библиотеку Go.
- При одновременных вызовах для одного канала каждый результат должен
  соответствовать фактически выполненной отправке.

## Примеры

```text
Вход: ch := make(chan int, 1); TrySend(ch, 8); TrySend(ch, 9); <-ch
Выход: true, false, 8
```

```text
Вход: var ch chan int; TrySend(ch, 5)
Выход: false
```

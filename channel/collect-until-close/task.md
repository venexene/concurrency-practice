# 012. Собрать значения до закрытия канала

**Сложность:** Easy

**Темы:** каналы, получение значений, закрытие канала

## Условие

Реализуйте функцию:

```go
func Collect(in <-chan int) []int
```

Функция получает канал только для чтения и должна последовательно прочитать
из него все значения до его закрытия. Верните значения в слайсе в том же
порядке, в котором они были получены.

Если канал уже закрыт и не содержит значений, верните пустой ненулевой слайс.
Функция возвращается только после закрытия входного канала и не должна
закрывать его сама.

## Ограничения

- Входной канал передаётся владельцем-производителем, который в итоге его
  закрывает.
- Значения могут приходить через небуферизованный или буферизованный канал.
- Порядок полученных из одного канала значений сохраняется.
- Используйте стандартную библиотеку Go.
- Не используйте `time.Sleep`, активное ожидание и заранее известное число
  значений.
- `nil`-канал не является допустимым входом: чтение из него блокируется
  навсегда, поскольку его невозможно закрыть.

## Примеры

```text
Входной поток: 4, -1, 7; затем close
Выход: [4, -1, 7]
```

```text
Входной поток: close
Выход: []
```

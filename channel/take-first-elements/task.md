# 016. Взять первые n

**Сложность:** Easy

**Темы:** каналы, ограниченное чтение, закрытие канала

## Условие

Реализуйте функцию:

```go
func Take(in <-chan int, n int) []int
```

Прочитайте из `in` не более `n` значений и верните их в порядке получения.
Функция должна остановиться после `n`-го значения или раньше, если канал
закрылся и больше не содержит значений. После `n`-го значения нельзя читать
из канала даже один дополнительный элемент: непрочитанный остаток остаётся
доступным вызывающему коду.

При `n == 0` верните пустой результат сразу, не пытаясь читать из канала.
Нулевое значение `int` — обычный элемент, а не признак окончания потока.

## Ограничения

- `0 <= n <= 10^5`.
- Не закрывайте входной канал: им владеет производитель. После раннего
  завершения `Take` тестовый драйвер отдельно сообщает производителю, что
  нужно остановиться.
- При `n > 0` функция может ждать следующее значение или закрытие канала.
  Вызывающий код отвечает за то, чтобы одно из этих событий произошло; API
  не принимает сигнал отмены.
- Используйте стандартную библиотеку Go. Не запускайте вспомогательные
  горутины и не используйте `time.Sleep` или активное ожидание.

## Примеры

```text
Вход: буфер in=[4, 5, 6], n=2; затем вызывающий код читает остаток
Выход: Take(in, 2)=[4, 5], остаток=[6]
```

```text
Вход: буфер in=[0, 7], затем close(in); n=3
Выход: Take(in, 3)=[0, 7]
```

```text
Вход: n=0; канал открыт и пуст
Выход: [] без ожидания
```

# 011. Генератор диапазона

**Сложность:** Easy

**Темы:** каналы, горутины, закрытие канала

## Условие

Реализуйте функцию:

```go
func Range(lo, hi int) <-chan int
```

Она должна запустить генератор в отдельной горутине и сразу вернуть канал
только для чтения. Генератор последовательно отправляет в канал все целые
числа из полуоткрытого диапазона `[lo, hi)`: начиная с `lo` и заканчивая
`hi - 1`.

После последнего числа генератор обязан закрыть канал. Если диапазон пустой
(`lo >= hi`), канал должен быть закрыт без отправки значений.

Потребитель читает значения обычным циклом `for range`.

## Ограничения

- `lo` и `hi` — любые значения типа `int`.
- Результат должен идти строго по возрастанию, без пропусков и повторов.
- `Range` не должна ждать, пока потребитель прочитает первое значение.
- Используйте стандартную библиотеку Go.
- Нельзя собирать весь диапазон в слайс перед отправкой.
- Отмена потребителя в этой версии задачи не поддерживается: вызывающий код
  должен дочитать канал до закрытия. Для отменяемого варианта нужен отдельный
  API с `context.Context` или каналом `done`.

## Примеры

```text
Вход: Range(3, 7)
Выход: 3, 4, 5, 6; затем канал закрыт
```

```text
Вход: Range(-2, 2)
Выход: -2, -1, 0, 1; затем канал закрыт
```

```text
Вход: Range(5, 5)
Выход: канал закрыт без значений
```

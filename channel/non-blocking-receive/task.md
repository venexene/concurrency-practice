# 015. Неблокирующее чтение без потери состояния

**Сложность:** Easy

**Темы:** каналы, `select`, закрытие канала

## Условие

Реализуйте функцию:

```go
func TryRecv(ch <-chan int) (value int, state string)
```

Она должна один раз попытаться прочитать из `ch` и сразу вернуть результат.
Возможны три состояния:

- `"value"` — значение прочитано; `value` содержит именно его, в том числе
  если оно равно нулю;
- `"empty"` — чтение сейчас заблокировалось бы; элемент не извлечён;
- `"closed"` — канал закрыт и больше не содержит значений; верните `value == 0`.

Если буферизованный канал закрыли с оставшимися значениями, сначала нужно
возвращать эти значения в порядке отправки. `"closed"` возвращается только
после исчерпания буфера. Для `nil`-канала возвращайте `"empty"` без ожидания.
При состоянии `"empty"` числовое значение результата не используется.

## Ограничения

- Не запускайте новые горутины и не используйте таймеры, `time.Sleep` или
  активное ожидание.
- Не закрывайте переданный канал и не извлекайте больше одного элемента за
  вызов.
- Используйте стандартную библиотеку Go. Канал может быть открытым,
  закрытым, буферизованным, небуферизованным или `nil`.

## Примеры

```text
Вход: ch := make(chan int, 1); TryRecv(ch); ch <- 0; close(ch);
      TryRecv(ch); TryRecv(ch)
Выход: состояния "empty", (0, "value"), (0, "closed")
```

```text
Вход: ch := make(chan int, 2); ch <- 4; ch <- 5; close(ch);
      TryRecv(ch); TryRecv(ch); TryRecv(ch)
Выход: (4, "value"), (5, "value"), (0, "closed")
```

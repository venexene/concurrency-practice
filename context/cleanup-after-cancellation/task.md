# 036. Очистка после отмены запроса

**Сложность:** Medium

**Темы:** `context.Context`, независимая отмена, значения контекста, лимит времени

## Условие

Представьте, что обработка запроса создала временный файл. Клиент
отключился, и контекст запроса отменился. Файл всё равно нужно удалить.
Если передать в функцию удаления отменённый контекст запроса, она может
сразу отказаться от работы. Для очистки нужен отдельный контекст:
с данными исходного запроса, но со своим ограничением времени.

Реализуйте функцию:

```go
func Cleanup(
    requestCtx context.Context,
    budget time.Duration,
    cleanup func(context.Context) error,
) error
```

`requestCtx` — контекст исходного запроса. Он может быть активным,
уже отменённым или с истёкшим дедлайном.

`budget` — время, отведённое на очистку с момента создания её контекста.
Это новый лимит, а не остаток времени исходного запроса.

`cleanup` — готовая функция очистки, переданная вызывающим кодом.
Удаление файла реализовывать не нужно: задача состоит в подготовке
контекста и вызове этой функции.

Контекст очистки должен сохранять значения `requestCtx`, но не зависеть
от его отмены и дедлайна. По истечении собственного `budget` он
отменяется с ошибкой `context.DeadlineExceeded`.

Вызовите `cleanup` ровно один раз, синхронно, и верните её результат.
`Cleanup` должна дождаться завершения очистки даже при истечении лимита.
После возврата ресурсы контекста очистки должны быть освобождены,
а его `Done()` закрыт.

## Ограничения

- `requestCtx` и `cleanup` не равны `nil`; `budget > 0`.
- `cleanup` завершается без паники. Если ей нужно долго ждать,
  она следит за переданным `ctx.Done()` и реагирует на его закрытие.
- Используйте стандартную библиотеку Go.
- Не задавайте порядок событий через `time.Sleep` и не используйте
  активное ожидание.

## Примеры

```text
Вход: requestCtx уже отменён; в нём есть requestID="abc";
      budget=100 ms; cleanup читает requestID и возвращает nil
Результат: cleanup видит "abc" и активный контекст со своим дедлайном;
           Cleanup возвращает nil
```

```text
Вход: дедлайн requestCtx наступит через 10 ms; budget=100 ms;
      cleanup ждёт закрытия переданного ctx.Done() и возвращает ctx.Err()
Результат: дедлайн запроса не останавливает очистку;
           после её собственного лимита Cleanup возвращает
           context.DeadlineExceeded
```

```text
Вход: requestCtx отменяют, пока cleanup работает;
      cleanup заканчивает до своего дедлайна и возвращает ErrCleanup
Результат: Cleanup возвращает ErrCleanup;
           контекст очистки отменён при выходе
```

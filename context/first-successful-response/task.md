# 035. Первый успешный ответ

**Сложность:** Medium

**Темы:** параллельные вызовы, отмена проигравших, сбор ошибок

## Условие

Реализуйте функцию:

```go
func FirstSuccess(
    ctx context.Context,
    calls []func(context.Context) (string, error),
) (string, error)
```

Каждый элемент `calls` — функция, которая получает контекст и
возвращает строковый ответ либо ошибку. Запустите вызовы конкурентно,
передавая им дочерний контекст операции.

Первый **зарегистрированный** успешный ответ побеждает. Отмените
контекст остальных вызовов, дождитесь их завершения и верните ответ
с `nil`. Пустая строка тоже считается успехом, если ошибка равна
`nil`. Ошибка одного вызова не отменяет соседей.

Если все функции завершились с ошибками и успеха не было, верните
пустую строку и `AllFailed`. Это тип ошибки, который реализует
`error` и хранит ошибки всех вызовов **в порядке входного среза**, а
не в порядке завершения. Если внешний `ctx` отменён до регистрации
победителя, верните пустую строку и `ctx.Err()`, предварительно
дождавшись остановки запущенных вызовов. Если функция завершилась с
успехом уже после внешней отмены, такой успех не побеждает, даже если
вызов на отмену отреагировал.
Когда события конкурируют без заданного порядка, допустим исход,
зарегистрированный первым.

## Ограничения

- `1 <= len(calls) <= 100`; `ctx` и элементы `calls` не равны `nil`.
- Вызовы реагируют на отмену переданного им контекста и завершаются
  без паники. Отмена не может принудительно остановить произвольную
  функцию, поэтому ожидание завершения обязательно.
- Вызывающий код не меняет `calls` во время вызова `FirstSuccess`.
- Используйте стандартную библиотеку Go; не задавайте порядок
  завершения через `time.Sleep` или активное ожидание.

## Примеры

```text
Вход: A возвращает ErrA; B возвращает "ok"; C ждёт отмены
Выход: ("ok", nil); ошибка A не мешает B, C завершён до возврата
```

```text
Вход: A возвращает ErrA; B возвращает ErrB; B завершился раньше A
Выход: ("", AllFailed{ошибки: [ErrA, ErrB]})
```

```text
Вход: A и B ждут отмены; отменить внешний ctx
Выход: ("", context.Canceled); оба вызова завершены
```

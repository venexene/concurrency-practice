# 034. Параллельный map с первой ошибкой

**Сложность:** Medium

**Темы:** горутины, отмена контекста, первая ошибка, ожидание завершения

## Условие

Реализуйте функцию:

```go
func MapAll(
    ctx context.Context,
    nums []int,
    f func(context.Context, int) (int, error),
) ([]int, error)
```

Запустите отдельную горутину для обработки каждого элемента `nums`.
Каждый вызов `f` получает контекст операции и соответствующий элемент.
Если все вызовы завершились без ошибок, верните новый срез результатов
в том же порядке, что и входные элементы, и `nil`. Порядок завершения
горутин может отличаться от порядка элементов. Входной `nums` не меняйте.
Пустой вход даёт пустой результат без вызовов `f`.

Первая **зарегистрированная** ошибка `f` отменяет контекст остальных
вызовов. Не начинайте возвращать результат, пока все запущенные
обработчики не завершатся. Верните `nil` и эту ошибку, без частичного
среза результатов. Если внешняя отмена `ctx` зарегистрирована первой,
допустимо вернуть `ctx.Err()`; если она пересеклась с ошибкой `f`,
первым может оказаться любое из этих событий. Не выбирайте ошибку по
номеру элемента: важен порядок регистрации конкурирующих событий.

## Ограничения

- `len(nums) <= 1000`; `ctx` и `f` не равны `nil`.
- `f` реагирует на отмену полученного контекста и завершается без
  паники. Отмена не может принудительно остановить произвольную
  функцию, поэтому `MapAll` всё равно ожидает её возврата.
- Вызывающий код не изменяет `nums` во время вызова `MapAll`.
- Используйте стандартную библиотеку Go; не устанавливайте порядок
  выполнения через `time.Sleep` или активное ожидание.

## Примеры

```text
Вход: nums=[3,1,2]; f(ctx,x)=(x*10,nil); обработчики завершились
      в порядке 2,3,1
Выход: ([30,10,20],nil)
```

```text
Вход: nums=[1,2,3]; f для 2 возвращает ErrBad, остальные ждут
      отмены полученного контекста и затем завершаются
Выход: (nil,ErrBad); все три обработчика завершены до возврата
```

```text
Вход: nums=[]
Выход: (пустой срез,nil); f не вызвана
```
